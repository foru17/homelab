# 安全基线

不讲细节，只讲原则；逐条对照检查。

1. **管理面不上公网。** 各种面板（代理面板、探针、导航页、NAS）只在 tailnet / 内网可访问，公网请求一律拒绝。在外访问靠 DNS：面板域名在内部解析成 tailnet 地址。
2. **家宽出口只出不进。** hub 能连家宽出口，家宽出口连不回 hub；家宽侧只开最小入站，强制鉴权。
3. **对外入口都要鉴权。** 代理入站有密钥；订阅链接带令牌或走审批；入口机按需加白名单。
4. **最小暴露端口。** 防火墙默认拒绝；Docker 映射的端口会绕过 ufw，要在 `DOCKER-USER` 链里限制。
5. **凭据不进 git。** 密码、UUID、令牌、订阅链接放密码管理器或本地 `.env`（已忽略）。
6. **多地加密备份。** 配置和数据每天自动备份到两个以上地点，加密后再传。
7. **计费有上限。** 按量计费的云资源（流量、函数、CDN）先配预算告警和硬上限，再上线。
8. **境外机器不用国内 DNS。** 境外服务器用 1.1.1.1 / 8.8.8.8 等；tailnet 不要覆盖服务器本地 DNS。
9. **公开分享前脱敏。** 去掉 IP、域名、端口、家庭所在城市、他人信息、订阅地址。
